# Sysroot

The libraries every Dolly program links, rebuilt inside Dolly from the pinned
sources and compared with the ones the seed ships
(`tasks/20260930-232236-llvm-in-dolly`). The seed keeps shipping the
container's: the first link of a root build needs them.

## Images

- `sysroot`: build-only: the process sysroot's libraries, compiled in Dolly.
  musl libc without the members Dolly replaces, dlmalloc, the standalone glue
  and the stubs with the flags of Emscripten's own build, and Dolly's start
  file, libc adapter and host clients; each for one thread and for pthreads.
  It keeps `/usr/lib/sysroot`; no image links it.

[`test/sysroot.artifacts.mjs`](test/sysroot.artifacts.mjs) (`npm run
test:artifacts`) holds each file against the seed's: the same members, equal
in every section but the compiler's name, except the assembly members, which
`cc` can only take as file-scope asm.
[`test/sysroot-browser.mjs`](test/sysroot-browser.mjs) links programs with
them in Chromium and Firefox and gets the bytes of the usual link.

Key files: [`Dollyfile-sysroot`](Dollyfile-sysroot), [`units.mk`](units.mk)
(the sources of each Emscripten archive, generated by
[`list-units.py`](list-units.py) from `tools/system_libs.py` in the pinned
container; generate it again when the Emscripten pin moves) and
[`prepare-sources.sh`](prepare-sources.sh).
