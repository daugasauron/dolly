## State (2026-11-11)

Done on `fix/donna-data`: `scripts/build.sh` writes `dist/dolly-abi.json`
(`scripts/abi-data.mjs`) once the digests exist. It is the generated modules the browser
imports, written as JSON: `process` (the digest, `process.h`'s constants, errno numbers,
`sizeof` and `offsetof` of each of its 46 packet structs), `kernelPlugin` (the digest), `host`
(`dolly-host-0.wat`'s constants) and `modules` (each manifest, its contracts' constants and
digest). `scripts/generate-abi-constants.mjs` lays the structs out (each field at a multiple of
its alignment) into `DOLLY_PROCESS_SIZEOF` and the new `DOLLY_PROCESS_OFFSETOF`, and writes
`build/process-abi-check.c`, whose `_Static_assert`s on `sizeof` and `offsetof` the build
compiles; the 38 sizes `process.h` declares came out unchanged. The supervisor's spawn packet
and the process Worker's clock fast path now use the offsets instead of numbers.
`test/process-abi.test.mjs` checks the file equals what the modules give.

## Today

- Constants and exported functions of each contract are in its assembled `dist/dolly-*-0.wasm`
  (globals), which any language reads.
- What only JavaScript and C get: `include/dolly/process.h`'s operation numbers, packet sizes
  and offsets and the errno numbers (`scripts/generate-abi-constants.mjs` writes
  `src/process-constants.mjs`, `DOLLY_PROCESS_SIZEOF`, and each `host/NAME/abi.mjs`), and every
  `DOLLY_NAME_ABI_DIGEST` (`scripts/dolly-abi.mjs`; `dist/dolly-process-abi.mjs` carries the
  process digest). A host in Rust must either run Node or retype them, and a retyped digest or
  offset is the drift a contract exists to prevent.

## Wanted

- One generated, language-neutral file per contract, or one for all, beside the `.wasm`
  contracts in `dist/`: operation numbers, struct sizes and field offsets the host reads,
  errno numbers, the ABI digest, and the module's manifest fields (`gives`, `fixed`).
  JSON is acceptable: AGENTS.md allows generated JSON when a tool requires it, and the WAT stays
  the source. Alternatively the constants as globals of the assembled contracts, as they are
  already for module constants.
- The browser's `.mjs` and the new file come from one generator, so they cannot disagree.
