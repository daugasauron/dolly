DOLLY

A small POSIX-like coding-agent userspace contained in one browser WebAssembly machine. Pick an image or rebuild it visibly from source.

Images

default

The base tool environment. Starts /bin/slop.

open → rebuild Dollyfile

pi

Default plus QuickJS and Pi. Starts /usr/bin/pi.

open → rebuild Dollyfile

python

Focused CPython runtime and native-extension SDK. Starts /bin/slop.

open → rebuild Dollyfile

python-pi

Pi plus CPython. Starts /usr/bin/pi.

open → rebuild Dollyfile

gamedev

Pi plus raylib and Box3D. Starts /usr/bin/graphics-demo.

open → rebuild Dollyfile
